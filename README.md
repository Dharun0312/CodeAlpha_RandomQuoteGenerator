
# Random Quote Generator

## Project Description
The Random Quote Generator is a simple Python GUI application that displays random motivational quotes along with their authors.

## Features
- Displays a random quote when the application starts.
- Shows the quote and author name.
- New Quote button to generate another quote.
- Simple and user-friendly interface.

## Technologies Used
- Python
- Tkinter
- Random Module
- Visual Studio Code

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python quote_generator.py

- quote_generator.py - Main Python application.
