🌟 Random Quote Generator

A simple and interactive desktop application built using Python and Tkinter that displays random motivational quotes to inspire users.

📌 Project Description

The Random Quote Generator is a Python GUI application that displays motivational quotes with their authors. Users can generate new quotes by clicking the New Quote button.

✨ Features

- Displays a random motivational quote when the application starts.
- Shows the quote author's name.
- Generates a new random quote with one click.
- Simple and user-friendly graphical interface.
- Attractive dark-themed design.
- Lightweight and easy to use.

🛠️ Technologies Used

- Python 3
- Tkinter
- Random Module
- Visual Studio Code

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/Dharun0312/CodeAlpha_RandomQuoteGenerator.git

2. Open the project folder
cd CodeAlpha_RandomQuoteGenerator

3. Run the application
python main.py

On Windows, you can also use:
py main.py

🖥️ How to Use
Run the Python application.
A motivational quote appears automatically.
Read the displayed quote and author.
Click the New Quote button to generate another quote.

🎯 Project Objective
The main objective of this project is to understand Python programming, GUI development using Tkinter, and random selection using Python's Random module.
